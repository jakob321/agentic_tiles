# Security policy

Agentic Tiles controls a coding agent that can execute commands and modify files. Treat permission
defaults and prompts with the same care as direct terminal access.

Please do not open a public issue for a vulnerability that could expose user data or execute code
unexpectedly. Use GitHub's private vulnerability reporting for this repository instead.

Agentic Tiles does not bundle the Codex CLI. Security issues in Codex itself should be reported
through OpenAI's official security channels.
